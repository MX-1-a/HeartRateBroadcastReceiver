HeartRateBroadcastReceiver v1.0

基于 PyQt5 的蓝牙心率广播接收器桌面应用

核心功能：
- 蓝牙心率监测 — 自动扫描连接 BLE 心率设备，实时接收心率数据
- 心跳动画 — 心形图标跟随心率节拍跳动
- 弹窗心率窗口 — 可拖拽、可缩放的悬浮心率显示
- 自动重连 — 蓝牙断开后自动重连（最多10次）

数据记录与分析：
- 实时记录 — 按日期自动保存心率数据（JSON）
- 数据导出 — 支持 CSV 和 Excel 格式
- 心率图表 — 折线图、心率热图、趋势图
- 统计面板 — 最大/最小/平均心率统计
- 睡眠分析 — 自动检测睡眠时段，质量评分与建议
- HRV 分析 — 心率变异性分析

其他特性：
- 卡路里计算（基于体重/年龄/性别）
- OBS 直播集成（输出心率到文本文件）
- 三套主题：暗夜红心 / 极光蓝 / 暖阳橙
- 系统托盘支持
- 自动更新检查
- 数据存储位置可自定义

运行环境：
- Windows 10/11（需蓝牙 BLE 支持）
- Python 3.8+

安装与运行：
pip install -r requirements.txt
python main.py
